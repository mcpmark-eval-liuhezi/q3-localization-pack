# Orbital Sync v3.2.1 — Release Announcement (Q3 Localization Pack)

Official release announcement for Orbital Sync v3.2.1, localized for the Q3 launch. The English master copy appears first, followed by verified translations in German, French, Spanish, Italian, Japanese, and Brazilian Portuguese.

## English

We are excited to announce that Orbital Sync v3.2.1 is now available to all customers. This release introduces faster dashboard loading, improved calendar sharing, and a redesigned mobile experience.

Starting this quarter, workspace owners can set per-project budgets and receive weekly spending summaries by email. These features are enabled automatically, and no migration steps are required.

Please update at your convenience. Our support team is standing by if anything goes wrong. Thank you for helping us build a better product.
